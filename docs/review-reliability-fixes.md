## 行为变化

- 短、长聊天都直接注入档案事实，相关问题补入家庭、室友、偏好、相识与纪念日。她的学校和实习不属于对方；空字段仍未知。
- 公开搜索通过 `SEARCH_QUERY` 请求，由固定 browser-skill/bsk 适配器在 Mac mini 已登录小红书的新 Agent Window 执行一次有界查询。只有解析到相关来源才提供搜索成功证据；无结果、验证码、超时都自然说明未查到。预览和离线测试不访问网络。2026-10-29 Mac mini 的模型原生搜索虽然返回来源，但 CLI 权限负例未通过，因此正式聊天默认浏览器，不开放通用 agent 命令能力。浏览器实例通过本地配置指定；只读笔记标题、链接、可见正文，随后结束自己的会话，不借用现有标签。个人笔记作为作者说法，不当成官方结论。
- 生成时不宣称图片已发送或事实已写入长期记忆。QQ 唯一 echo 匹配平台 ACK；iLink/HTTP 检查响应。确认成功的部分才入聊天、日记和人格计数。未知发送保留占位，不自动重发；ACK 仅表示平台接收，并不证明用户已读。
- 入口、出口只处理映射到 demo_contact 的联系人。主动轮次以实际确认内容记账，原频率/配额不变。
- 日程只约束她的当下活动陈述，保留对方、过去、未来、否定。普通生活照绑定她的地点；明确想象场景带标记，不当成真实经历。
- 真正告别和晚安共用语义判断，否定/引述/未来睡觉建议不建立整夜暂停。17:00–07:00非告别仍热情。旧跨日睡眠只做当前/未来的兼容投影，不重写冻结日程、不改已执行历史。
- “你好凶/敷衍”等反馈优先修复语气；第三方情绪不直接降低关系亲密度。“病毒实验/吃菜”不再误判关系情绪；普通“好啦/点心”不触发粤语。
- 反思使用记录日期和独立会话。事实抽取只接受可定位到对方原话的证据；校园新闻保持听说。回复超长先请求压缩，最终保底不留下会反转意思的半句。
