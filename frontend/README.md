# Persona Runtime 本地工作台

示例人设事实来源见[人设档案](../data/persona_dossier.json)。

## 打开控制台

在仓库根目录准备[示例配置和依赖](../README.md#本地启动)后运行以下命令。

```bash
.venv/bin/python tools/persona_console_server.py --port 5174 --environment dev
```

打开 [首页画廊](http://127.0.0.1:5174/) 或 [工作台总览](http://127.0.0.1:5174/?view=overview)。同一个服务提供页面和 `/api/*`。顶部标签显示代码所在的 Git 分支。`--data-dir` 可指定独立的控制台数据目录。

## 创建伙伴

1. 从首页选择「开始挑选你的伙伴」。在本机安装 Codex CLI 并完成 ChatGPT 授权，上传同一位成年人物的脸部和全身参考。
2. 依次确认脸部五视图、正面全身基准和全身五视图。选择预设，提交定制需求并回答建档问题。
3. 核对预览，确认进入工作台。未完成的草稿可以用原创建页链接继续。
4. 在「07 部署绑定」输入自己的 QQ 号、OneBot 正向 WebSocket 地址和访问令牌。探测连接并确认 Bot 账号后启用私聊。「09 工作流诊断」显示授权、素材、版本和 OneBot 回执。

## 编辑与应用

- **人设**。保存草稿，预览变更，再应用版本。在「05 个性化设置」可查看历史版本并回退。页面分别显示选中的版本和工作流实际加载的版本。
- **日程与路线**。周模板和单日覆盖由后台保存。日期覆盖优先，明确清空某天时保存空列表。路线编辑按角色保存。
- **外貌**。确认生成候选后再应用。改变身高或其他外貌参数后，相关标准素材需要重新确认。
- **导出**。读取后台已保存的草稿、应用版本、日程、路线和加载状态。运行态的聊天、情绪和亲密度在工作台只读展示。

人设草稿和版本保存在 `data/persona_personalization/<environment>/`。日程覆盖和路线分别保存在 `data/ui_schedule_overrides.json` 和 `data/persona_locations.json`。新建伙伴使用独立运行目录和本机凭据文件。
